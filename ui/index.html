      ⌨️ Navegación 100% por Teclado y Mouse

      Navegación y Paneles

      • ↑ ↓ o j k Mover cursor
      • Enter o l Abrir carpeta / archivo
      • Backspace o h Subir al directorio padre
      • Tab Cambiar entre Panel Izquierdo y Derecho
      • Espacio Seleccionar/Deseleccionar ítem actual
      • Ctrl+A Seleccionar todos los elementos
      • Ctrl+L Editar barra de dirección manualmente
      • Ctrl+F o / Filtrar archivos en tiempo real

      Pestañas, Vistas y Operaciones

      • Ctrl+T Nueva pestaña en el panel activo
      • Ctrl+W Cerrar pestaña actual
      • Ctrl+Tab Siguiente pestaña
      • F2 Renombrar elemento seleccionado
      • F3 Activar / Desactivar Doble Panel
      • F4 Mostrar / Ocultar Terminal Integrada
      • F5 Copiar selección al panel opuesto
      • F6 Mover selección al panel opuesto
      • F7 Crear nueva carpeta
      • F8 / Supr Eliminar selección
      • F11 Alternar panel de Vista Previa
